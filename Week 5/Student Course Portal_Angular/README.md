# Student Course Portal — Angular v20 (Part 1)

Digital Nurture 5.0 hands-on submission — Hands-On 1 through Hands-On 5.

## Running the project

```
npm install
npm start
```

Then open http://localhost:4200.

## What's covered here

- Hands-On 1: workspace scaffold, HeaderComponent, HomeComponent, CourseListComponent, StudentProfileComponent
- Hands-On 2: interpolation, property/event/two-way binding, ngOnInit/ngOnDestroy/ngOnChanges, @Input/@Output on CourseCardComponent
- Hands-On 3: *ngIf/*ngFor/*ngSwitch, ngClass/ngStyle, HighlightDirective, CreditLabelPipe
- Hands-On 4: EnrollmentFormComponent — template-driven form with validation
- Hands-On 5: ReactiveEnrollmentFormComponent — FormBuilder, custom sync validator, async validator, FormArray

Hands-On 6–10 (services/DI, routing guards, HTTP client, NgRx, testing) are in the
separate Part 2 zip, which builds directly on top of this project.
